AZET Pass Lite는 무료 오픈소스 비밀번호 관리자입니다. 로그인·카드·메모를 종단간 암호화로 보관하고, 앱과 브라우저에서 자동으로 채우며, 2단계 인증 코드도 보여 줍니다. 모든 기능을 그대로 씁니다.

무엇이 다른가요
• 브라우저에 들어 있는 비밀번호 목록과 달리, 휴대폰의 모든 앱과 브라우저에서 쓰고 pass.azet.io로 다른 기기와도 맞춰집니다.
• 2단계 인증 코드를 유료 이용자에게만 주는 관리자와 달리, 인증기(TOTP) 코드를 누구나 씁니다.
• 오픈소스: Bitwarden 코드(GPL-3.0) 위에 만들었고, 소스는 github.com/neulketing/azet-pass 에 있습니다.

기능
• 로그인·카드·신원·보안 메모·SSH 키를 개수 제한 없이
• 안드로이드 자동완성 서비스로 앱·브라우저에서 자동 입력
• 내장 인증기: 로그인마다 2단계 인증(TOTP) 코드
• 비밀번호·암호 문구·사용자 이름 생성기
• Send: 기한을 정해 글이나 파일 공유
• 패스키, 생체 인증 잠금 해제, 자동 잠금 시간
• 폴더·검색·즐겨찾기

보안
• 제로 지식 종단간 암호화: 마스터 비밀번호는 기기 밖으로 나가지 않고 AZET도 보관함을 읽을 수 없습니다
• 계정과 보관함은 pass.azet.io(AZET LLC)에 저장되며, 직접 운영하는 서버에 연결할 수도 있습니다
